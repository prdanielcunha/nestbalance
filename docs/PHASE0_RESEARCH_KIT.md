# Phase 0 Moderated Research Kit

This kit turns the roadmap's human-research requirement into a repeatable test. It intentionally avoids asking for real balances or documents.

## Session setup

Use a synthetic Household with realistic but invented data. Ask the participant to narrate what they believe will happen before each action. Run once on a phone-sized viewport and once on desktop for the first-use tasks.

## Tasks

1. Enter the product and tell us what money is available now.
2. Tell us what still needs attention this month.
3. Add: "internet 119 dia 10".
4. Send a synthetic Pix screenshot and explain what the review screen is asking.
5. Import a synthetic invoice with installments and identify what is already committed next month.
6. Find the proof for a synthetic internet payment from a previous month.
7. Create or import a Savings Pot and explain whether the app moved money at the bank.
8. Ask how much is still left to pay and identify the data supporting the answer.
9. Change one item from Household to Personal and explain who can see it.
10. Invite/assume a second-adult role and explain Household vs Personal before adding anything.

## Observation form

For each task capture:
- success: yes / partial / no;
- elapsed seconds;
- first-action seconds;
- taps/clicks;
- backtracks;
- help required: none / prompt / direct instruction;
- confidence: 1–5;
- issue code from a fixed taxonomy;
- short researcher note with financial details removed.

Issue taxonomy: NAVIGATION, LANGUAGE, DENSITY, TRUST, SCOPE_PRIVACY, REVIEW_OVERLOAD, FEEDBACK, PERFORMANCE, ACCESSIBILITY, OTHER.

## Exit analysis

Rank friction by `frequency x impact`:
- frequency = participants affected / participants who attempted;
- impact 1 = cosmetic, 2 = slows task, 3 = causes uncertainty, 4 = blocks task, 5 = risks financial misunderstanding.

Phase 0 can only close after the five highest-scoring frictions are recorded with evidence and an owner for the Phase 1/2 response.
